# MTN TV+ — web client

Streaming web app for MTN TV+, built with React, Vite and Tailwind CSS on the Uniqcast Client API and TVAnywhere CRM.

## Getting started

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev                  # http://localhost:5173
```

Project notes live in [`wiki/`](wiki/index.md).
